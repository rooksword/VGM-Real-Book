# VGM Real Book Website

For a while now, I've been thinking about making a website where people can upload and share video game music lead sheets.

## What's Wrong with VGLeadSheets?

I really like [vgleadsheets.com](http://vgleadsheets.com/) however I have several ideas which are outside of the scope of VGLeadSheets. My website will differentiate itself by:

1. Accepting lead sheets from the community (following a review process)
2. Adding features such as transposition and basic notation editing
3. Incorporating original recordings and backing tracks

## Key Planned Features

- Allow community members to upload VGM lead sheets in an editiable format such as .musicxml (NOTE: this is important as it means you can just upload one file and the website will be able to automatically transpose the piece into any key!)
- Organise the community-provided lead sheets with search options and filters
- Display the lead sheet with options for page size and zoom
- Allow the user to transpose the piece into any key and change the clef

## Future Ideas

- Add MIDI playback with a cursor to highlight the current note
- Allow the user to listen to each tune's original recording synced with the note cursor
- Incorporate backing tracks (with each instrument able to be toggled on or off) 
- Turn the website into an app
